# Tabler Icons for Excalidraw.

A collection of 6,238 [Tabler Icons](https://github.com/tabler/tabler-icons) converted into native, editable elements for [Excalidraw](https://excalidraw.com).

Icon artwork by [Tabler Icons](https://github.com/tabler/tabler-icons) and its contributors, licensed under the MIT License. This project converts their SVG icons into editable Excalidraw libraries and is not affiliated with or endorsed by Tabler.

## Download.

Download the library you need from the **Releases** section of this repository. No installation or build tools are required.

- `tabler-icons.excalidrawlib` — the complete collection: 6,238 icons.
- `tabler-icons-outline.excalidrawlib` — 5,184 outline icons.
- `tabler-icons-filled.excalidrawlib` — 1,054 filled icons.

## Using the icons.

In Excalidraw, open the library panel, then use its menu to open or import a library file. Choose the complete collection or the variant you need. You can also drag an `.excalidrawlib` file onto the canvas and confirm the import. Importing a large collection and generating its thumbnails may take a moment.

Icons share a scale corresponding to a 96 × 96 unit area. Each icon is grouped; ungroup it to edit its individual parts. Outline icons use the stroke color, while filled icons use the background/fill color. Curves are approximated by polylines rather than preserved as original Bézier curves.
